# Python через об’єкти

Українська практична довідка з основ Python для початківців. Матеріал починається з маленької працюючої програми й майже відразу показує класи, об’єкти, їхній стан та поведінку. Теорія з’являється саме тоді, коли вона потрібна для наступного видимого результату.

[Відкрити інтерактивну довідку](https://artegas.github.io/python-oop-handbook-ua/) · [Завантажити PDF](https://artegas.github.io/python-oop-handbook-ua/downloads/python-cherez-obiekty.pdf)

У репозиторії є два синхронні формати:

- інтерактивний сайт GitHub Pages;
- PDF-книга для читання без браузера та друку.

Обидва формати збираються з файлів у `content/`, тому приклади, пояснення й вправи в них однакові.

## Що охоплює довідка

- запуск `.py` у VS Code й терміналі;
- змінні, прості типи, рядки та числа;
- класи, об’єкти, атрибути й методи;
- умови, списки, кортежі, цикли та словники;
- введення користувача, функції, модулі й імпорти;
- успадкування та композицію;
- стандартну бібліотеку;
- текстові файли, шляхи, винятки та JSON;
- автоматичні тести поведінки.

Тут немає інструкції зі встановлення редактора й немає великої проєктної частини. Це довідник: розділ можна читати послідовно або відкривати тоді, коли потрібна конкретна тема.

## Локальна збірка

Збірка використовує стабільні версії ReportLab для PDF і pytest для автоматичних перевірок.

### Windows PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe tools\build.py
```

### Linux і macOS

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements-dev.txt
./.venv/bin/python tools/build.py
```

Команда оновлює сайт у `docs/`, PDF у `output/pdf/` і машинний звіт у `reports/verification.json`.

Окремо запустити тести самої збірки можна так:

```powershell
.\.venv\Scripts\python.exe -m pytest -q tests
```

Готовий сайт не потребує сервера застосунку: це звичайні HTML, CSS і JavaScript, придатні для GitHub Pages.
